Equipment and repair management for WordPress admin.

== Description ==

This plugin provides the foundation for an equipment and repair management system.

== Installation ==

1. Upload the `equipment-management` directory to `/wp-content/plugins/`.
2. Activate the plugin from the WordPress Plugins screen.
